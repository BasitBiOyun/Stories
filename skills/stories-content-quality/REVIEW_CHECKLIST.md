# Stories Content Review Checklist

Use this checklist for each story, CEFR level, and language.

## Scope

- [ ] Story id, level, and language are identified.
- [ ] All canonical story pages were read in full.
- [ ] No work is based only on summaries, another level, or the other language.
- [ ] The exact derived files in scope are listed.
- [ ] The reading stage of each activity is clear: before, while, after, or final.

## Canonical protection

- [ ] Canonical `pages.ts` story content is unchanged.
- [ ] Chapter titles, boundaries, order, and ids are unchanged.
- [ ] Narration, audio references, and synchronization data are unchanged.
- [ ] Canonical hash validation passes without baseline modification.
- [ ] A pilot contract test compares protected story fields when an overlay/derived layer is used.

## Evidence

- [ ] Every objective question has identifiable evidence in the same canonical book.
- [ ] No external religious or historical fact is required to answer a scored item.
- [ ] Inference questions are supported by the text and appropriate for the level.
- [ ] Reflection prompts are clearly separated from factual assessment.
- [ ] Uncertain or disputed interpretations are flagged for human review.

## Source-style alignment

- [ ] Questions fit the discourse/style of the source text.
- [ ] Informative narrative/essay-like texts use appropriate operations such as fact retrieval, sequence, comparison, cause/result, vocabulary in context, main idea, and short summary.
- [ ] Questions do not create game-show difficulty that is unrelated to the reading goal.
- [ ] Question wording is not harder than necessary simply to appear challenging.

## CEFR

- [ ] Instructions match the declared level.
- [ ] Question syntax and vocabulary match the declared level.
- [ ] Expected learner output matches the declared level.
- [ ] Cognitive demand matches A2, B1, or B2 expectations.
- [ ] Complexity is pedagogically meaningful rather than decorative.

## Exercise construction

- [ ] Exercise ids are unique and stable.
- [ ] Scored exercises have valid answer data.
- [ ] Multiple-choice items contain exactly one correct option.
- [ ] Distractors are plausible, parallel, and text-grounded.
- [ ] True/false items contain one unambiguous claim.
- [ ] Matching pairs use one consistent relationship.
- [ ] Sequencing order is established by the canonical text.
- [ ] Fill-in-the-blank tasks have one clear expected answer.
- [ ] Exercise types are varied across the book.

## Feedback

- [ ] Correct feedback confirms the relevant learning point.
- [ ] Incorrect feedback gives a useful hint or redirection.
- [ ] At A2/B1, wrong-answer feedback normally supports evidence finding, rereading, and a second attempt.
- [ ] Feedback is not empty, punitive, vague, or misleading.
- [ ] Personal reflections are not marked wrong.
- [ ] Explanations do not introduce unsupported facts.

## Vocabulary

- [ ] Each word is present in or directly necessary for the canonical text.
- [ ] Definitions are level-appropriate and context-specific.
- [ ] Examples do not invent story facts.
- [ ] Duplicate entries are removed or intentionally recycled.
- [ ] B1 collocations and B2 nuanced meanings are used where justified.

## Quick Challenge

- [ ] Each challenge has a defined chapter or chapter-group scope.
- [ ] At A2/B1, the primary purpose is teaching/reinforcement rather than high-stakes measurement.
- [ ] It reinforces important comprehension, text structure, sequence, cause/result, or language from the current reading scope.
- [ ] A learner who answers incorrectly is given a realistic route back to the text.
- [ ] It is short enough to remain a while-reading/post-chapter learning activity.
- [ ] It does not duplicate the Final Challenge without purpose.
- [ ] B2 may combine reinforcement with stronger assessment/challenge demands.

## Review Challenge

- [ ] A2 contains exactly 8 objective Review Challenge questions.
- [ ] B1 contains exactly 8 objective Review Challenge questions.
- [ ] B2 contains exactly 8 objective Review Challenge questions.
- [ ] Questions consolidate important information across the intended review scope.
- [ ] For A2 print, the approved layout contract is 4 + 4 questions.

## Final Challenge

- [ ] A2 contains exactly 10 scored objective questions.
- [ ] B1 contains exactly 10 scored objective questions.
- [ ] B2 contains exactly 10 scored objective questions.
- [ ] Reflection items are not counted as objective questions.
- [ ] Questions cover the whole book rather than only the final chapters.
- [ ] Final questions emphasise retrieval/remembering of important information.
- [ ] B2 includes appropriate evidence/inference/evaluation demand without abandoning recall support.
- [ ] Print layout contract is 5 + 5 questions.

## Teacher guide

- [ ] Each chapter section maps to a real chapter or clear whole-book stage.
- [ ] Timing is realistic.
- [ ] Objectives are measurable.
- [ ] Lesson steps can be followed without reconstruction.
- [ ] Before-, during-, and after-reading stages are distinguishable.
- [ ] Quick Challenges are described according to their formative/reinforcing purpose.
- [ ] Discussion prompts are text-grounded.
- [ ] Support for struggling learners is practical.
- [ ] Fast-finisher extension is meaningful.
- [ ] Formative assessment or exit evidence is provided.
- [ ] Facts, interpretation, and reflection are distinguished.

## Self-study guide

- [ ] Instructions work without a teacher.
- [ ] Before-, during-, and after-reading actions are clear.
- [ ] Narration use is explained.
- [ ] Vocabulary/Word Notes use and review are explained.
- [ ] Learners are told that Quick Challenges can be used as learning practice.
- [ ] Learners are told how to use exercise feedback and reread evidence.
- [ ] A recovery step is provided after a weak/wrong response.
- [ ] Whole-book recall before Review/Final Challenge is explained.
- [ ] No unavailable classroom resource is assumed.

## English–Arabic parity

- [ ] The same chapters are covered.
- [ ] Learning objectives are equivalent.
- [ ] Cognitive demand is comparable.
- [ ] Review Challenge count is 8 in both languages.
- [ ] Final Challenge count is 10 in both languages.
- [ ] Guide coverage is comparable.
- [ ] Every factual item is answerable from its own language's canonical text.

## Safeguards

- [ ] Canonical terminology and framing are preserved.
- [ ] No dialogue, motive, revelation, or historical detail is invented.
- [ ] Sacred subjects are handled respectfully.
- [ ] Sensitive/violent material is not gamified or dramatized for entertainment.
- [ ] Moral reflection is not reduced to ridicule, punishment language, or one compulsory personal answer.
- [ ] Ambiguity is escalated instead of silently resolved.

## Release gate

- [ ] Structural validation passes.
- [ ] Runtime and PDF behavior remains intact.
- [ ] Canonical grounding has no failure.
- [ ] Religious, historical, and cultural safeguards have no failure.
- [ ] Rubric score is at least 85/100.
- [ ] Human review items are documented.
