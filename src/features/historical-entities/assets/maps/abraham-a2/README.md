# Abraham A2 historical maps

Book-specific historical map assets for Abraham A2 live here.

Naming convention:
- `abraham-a2-babylon-en.*`
- `abraham-a2-babylon-ar.*`
- `abraham-a2-mesopotamia-en.*`
- `abraham-a2-mesopotamia-ar.*`
- `abraham-a2-syria-en.*`
- `abraham-a2-syria-ar.*`
- `abraham-a2-palestine-en.*`
- `abraham-a2-palestine-ar.*`
- `abraham-a2-mecca-en.*`
- `abraham-a2-mecca-ar.*`

Maps should use the shared historical-map house style, keep borders/extent explicitly approximate where the historical record is uncertain, and avoid implying story events beyond the authored story text.
