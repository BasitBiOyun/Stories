# Musa (moses) – Language Focus matching audit

Source: `scratchpad/dumps/musa.txt`, grounded against `src/data/moses/{a2,b1,b2}/{en,ar}/pages.ts` (chapter `content`).
Totals: 158 matching exercises. A2 32 (16 EN + 16 AR, always slot 1), B1 78 (3 per chapter × 13 × 2, MA-MA-MA-Reflection), B2 48 (1 per chapter × 24 × 2).

Legend: **KEEP** = matching stays the best interaction; **KEEP\*** = keep matching but re-author the pairs (retarget to vocabulary / form↔form / collocation, fix data). **CONVERT:x** = change type. "choose-form" = choose-the-correct-form (inline MC); "gap-fill (bank)" = fill-blanks with word bank; "EC" = error correction; "SB" = sentence building (chips); "transf." = transformation.
Neighbour types in the chapter set were checked so that the recommended type does not repeat the next exercise's type where avoidable.
